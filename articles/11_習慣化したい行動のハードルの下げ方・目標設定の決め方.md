# 習慣化したい行動のハードルの下げ方・目標設定の決め方

手帳の1月1日のページに、「毎日1時間勉強する」「毎日5km走る」と書いてある。そのすぐ下のページをめくると、1月中旬あたりで記録がぱったり途切れている。振り返ってみると、目標を立てた瞬間はやる気に満ちていて、「これくらいはできるはず」と思っていたのに、実際に毎日続けるとなると、その量がどれだけ重かったかに後から気づく。

「目標はスモールステップで」という話は、よく聞く。ただ、「スモールステップ」がどのくらいの大きさを指すのか、自分の場合に当てはめるとどうなるのかは、意外とはっきりしないままになっている人が多いと思う。小さすぎても物足りず、大きすぎれば続かない。この「ちょうどいい大きさ」の見つけ方こそが、実は一番言語化されていない部分だ。

この記事では、目標・行動量の大きさをどう決めるか、そしてそれをどう段階的に増やしていくかを、具体的な手順として扱っていく。

## この記事が向いていない人

まず、すでに自分に合った適量が分かっていて、問題なく続けられている人。この記事は「量の決め方が分からない」段階の悩みを扱うものなので、その段階を過ぎている人には物足りないかもしれない。

次に、資格試験や大会など、明確な締切があり、量を逆算して決める必要がある人。この記事は「無理なく続けるための量」の決め方を扱うもので、締切から逆算する量の設計とは考え方が異なる。締切がある場合は、まず必要な総量を先に計算するほうが優先度は高い。

それから、まだ何を習慣にしたいかすら決まっていない人。対象が定まっていない段階では、この記事の手順はまだ使いにくい。

## 全体の流れを3ステップで俯瞰する

1. 「ちょうどいい最小単位」を、実際に試しながら決める
2. 決めた最小単位を、どのタイミングで増やすかの基準を作る
3. 増やした後、うまくいかなかったときに戻す基準も先に決めておく

目標設定でつまずく人の多くは、最初の量を「気合いで決めて」しまっている。この記事では、気合いではなく、実際に試した結果から量を決める方法を扱う。

## ステップ1:「ちょうどいい最小単位」を実際に試しながら決める

最初から正解の量は分からない。だからこそ、決め打ちにせず、試しながら調整する前提で進める。

### 手順

1. 本来やりたいと思っている理想の量を、まず1つ書き出す(例:「毎日1時間勉強する」)
2. その理想の量を4分の1にした量を、最初の試し値として設定する(例:15分)
3. 試し値を3日間、実際にやってみる
4. 3日間やってみて、「物足りないと感じたか」「ぎりぎりだったか」「できなかった日があったか」を記録する
5. 「物足りない」が多ければ量を増やし、「ぎりぎり」ならそのまま、「できなかった日があった」ならさらに減らす

この3日間の試行は、正解を当てるためではなく、自分の体感を確かめるための期間だと考える。

### つまずきやすい点とその場対処

- 理想の量そのものが漠然としていて、4分の1にする基準がない → まず理想の量を、時間や回数など具体的な数字にしてから4分の1にする。「頑張る」のような言葉のままでは調整ができない
- 3日間試しても判断がつかない → 判断がつかない場合は「ぎりぎり」寄りだったとみなし、そのまま量を維持して様子を見る期間を延ばす

## ステップ2:増やすタイミングの基準を作る

最小単位が決まったら、それをいつ、どれだけ増やすかの基準も決めておく。この基準がないと、増やすタイミングを感覚で決めることになり、無理のある増やし方をしてしまいやすい。

### 手順

1. 「連続して◯日、物足りなく感じたら増やす」という条件を決める(例:5日連続で余裕があれば増やす)
2. 増やす量は、一気に理想の量へ戻さず、現在の量の1.2〜1.5倍程度にとどめる
3. 増やした直後の3日間は、再び「物足りない/ぎりぎり/できなかった」を確認する期間として扱う
4. このサイクル(増やす→3日試す→判断する)を繰り返しながら、少しずつ理想の量に近づける

急に量を増やすと、それがきっかけで挫折することがある。焦らず、何段階かに分けて理想の量に近づけていく前提を持っておく。

### つまずきやすい点とその場対処

- 増やすタイミングが来ても、増やすのが怖くて現状維持を続けてしまう → 「今のままでも問題ない」という選択肢も残しておく。無理に増やし続ける必要はなく、その量で満足しているなら、そこで止めてもいい
- 増やしたらすぐにきつくなり、また減らす羽目になった → それは失敗ではなく、ちょうどいい量を探すための情報が1つ増えたと捉える。減らした量から、また同じサイクルを回せばいい

## ステップ3:うまくいかなかったときに戻す基準を先に決めておく

量を増やしたあと、うまくいかない日が続くことがある。そのときにどこまで戻すかを、あらかじめ決めておくと、その場で迷わずに済む。

### 手順

1. 「2日連続でできなかったら、前の段階の量に戻す」という条件を決めておく
2. 戻す先は、直前の量ではなく、確実にこなせていた1〜2段階前の量にする
3. 戻した後は、再びステップ1・2のサイクルを回し、無理に急いで元の量に戻そうとしない
4. 戻すこと自体を「失敗」ではなく「量の調整」として記録に書く

戻る基準を先に決めておくと、実際にうまくいかなかったときも、その場で落ち込む代わりに「決めておいた通りに動く」だけで済む。

### つまずきやすい点とその場対処

- 戻すことに抵抗があり、無理な量のまま続けてしまう → 「戻す」は後退ではなく、続けるための調整だと考える。無理な量を続けて完全に止まるより、量を落としてでも続くほうが、最終的な到達点は近くなる
- 何度も戻りを繰り返して、全然量が増えていかない → その場合は、最小単位の設定自体が理想に対して小さすぎる可能性がある。理想の量そのものを見直すタイミングかもしれない


## まとめ

目標設定でつまずくのは、意志の問題ではなく、最初の量を気合いで決めてしまっていることが多い。理想の4分の1から試し、増やす基準と戻す基準を先に決めておく。このサイクルを回すだけで、自分にとって本当にちょうどいい量が、時間をかけて見えてくる。

まずは理想の量を1つ書き出すところから、今日試してみてほしい。
