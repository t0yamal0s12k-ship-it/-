# 忙しい・疲れている時期に習慣を途切れさせない縮小ルール

来週から繁忙期が始まる。手帳を開くと、平日はほぼ埋まっていて、帰宅時間も読めない。それを見た瞬間、頭の中で「今やっている習慣、たぶん今週は無理だな」という声が響く。

これは、サボり癖とはまったく別の話だ。意志が弱いわけでも、飽きっぽいわけでもない。単純に、時間と体力が普段より少ない状態が、数日から数週間続くというだけの話。それなのに、多くの人はこの時期を「習慣が途切れる時期」として、なかば諦めて過ごしてしまう。

繁忙期や体調不良の時期に関する記事は、意外と少ない。習慣化のノウハウの多くは「普段のコンディションでどう続けるか」を前提にしていて、「そもそも普段通りにできない時期をどう乗り切るか」まで書かれていることは少ない。

この記事では、忙しい・疲れているとわかっている時期に向けて、あらかじめ「縮小版のルール」を用意しておく方法を扱う。予防的に負荷を下げておくことで、習慣そのものを完全に止めずに済ませるのが狙いだ。

## この記事が向いていない人

まず、そもそも今、特別に忙しい時期を控えていない人。この記事は「これから忙しくなるとわかっている」状況に向けた内容なので、平常運転の人には少し的外れになる。

次に、体調が明確に悪く、休養そのものが最優先の人。発熱していたり、医師から安静を指示されていたりする状態では、習慣を続けることより休むことが先決だ。この記事のルールを適用するのは、あくまで「忙しいけれど機能はしている」状態の場合に限る。

それから、1回のサボりに強い罪悪感を持つタイプの人には、この記事だけでは足りないかもしれない。その場合は、失敗の基準そのものを見直す話と合わせて読む方が効果的だと思う。

## 全体の流れを3ステップで俯瞰する

1. 忙しい時期が来る「前」に、縮小版のルールを決めておく
2. 縮小版に切り替えるタイミングの基準を決めておく
3. 忙しい時期が終わったあと、元の量に戻す手順を決めておく

ポイントは、忙しくなってから考えるのではなく、忙しくなる前に決めておくという順番だ。渦中にいるときは判断力が落ちていて、細かいルール設計をする余裕がない。

## ステップ1:忙しい時期が来る前に、縮小版のルールを決めておく

普段のメニューをそのまま維持しようとするから、忙しい時期に「できなかった」という結果になる。最初から、忙しい時期専用の別メニューを用意しておく。

### 手順

1. 今の習慣を、普段の量(100%)・半分の量(50%)・最低限の量(10〜20%)の3段階に分けて書き出す
2. 最低限の量は、「これなら疲れていてもできる」と思える具体的な行動にする(例:筋トレなら「腕立て5回だけ」、練習なら「楽器を触るだけ」など)
3. 3段階それぞれを、紙かメモアプリに保存しておく

100%と50%はイメージしやすいが、10〜20%の設計が一番重要になる。ここが甘いと、忙しさに負けてゼロになってしまう。

### つまずきやすい点とその場対処

- 「最低限」のレベルを決めても、それすら面倒に感じる → さらに下のレベルを作る。「触るだけ」「道具を出すだけ」でもいい。ゼロとの間に、もう1段階挟めないか考える
- 3段階を決めるのに時間がかかりすぎる → 完璧に決めようとせず、5分だけ時間を取って仮のルールを作る。実際にやってみて後から調整すればいい

## ステップ2:縮小版に切り替えるタイミングの基準を決めておく

「忙しくなったら縮小版にする」というだけでは、実際には切り替えのタイミングを逃しやすい。多くの人は、普段の量ができなくなってから初めて「今日はもう無理だ」と気づき、結局ゼロになる。

### 手順

1. 「この状態になったら縮小版に切り替える」という具体的な条件を1つ決める(例:「帰宅が22時を過ぎたら」「予定表に3件以上の予定が入っている日は」など)
2. その条件を、カレンダーやスケジュール帳の見える場所にメモしておく
3. 条件に当てはまった日は、朝の時点で「今日は縮小版でいく」と決めてしまう(その日の夜まで判断を持ち越さない)

夜、疲れ切った状態で「今日はどうしようか」と考えるのが一番良くない。朝のうちに、その日のレベルを決めてしまう方が、判断の回数自体が減って楽になる。

### つまずきやすい点とその場対処

- 条件を決めても、当日つい忘れてしまう → 前夜にスケジュールを確認する習慣とセットにする。「明日の予定を見る→今日のレベルを決める」を1つの流れにしておく
- 縮小版に切り替えたのに、罪悪感が消えない → 縮小版は「サボり」ではなく「継続するための選択」だと言葉にして自分に言い聞かせる。ゼロにするより縮小版を選んだ方が、翌週の再開が圧倒的に楽になる

## ステップ3:忙しい時期が終わったあと、元の量に戻す手順を決めておく

縮小版で乗り切った後、そのまま低いレベルに居着いてしまうケースもある。忙しい時期が終わったことに気づかず、いつまでも最低限のまま過ごしてしまうパターンだ。

### 手順

1. 忙しい時期が終わる予定日を、カレンダーに先に書いておく
2. その日から3日以内に、縮小版から50%レベルに戻す予定を1つ決めて入れておく
3. 50%レベルを2〜3日試してから、100%に戻すかどうかを判断する(いきなり100%に戻さない)

段階的に戻すのは、忙しい時期の疲れがすぐには抜けないからだ。いきなり元の量に戻すと、そこでまた挫折しやすくなる。

### つまずきやすい点とその場対処

- 忙しい時期がいつ終わるか、はっきりしない → 「終わる予定日」ではなく「見直しをする日」として、2週間後などに仮の日付を入れておく。その日に状況を見て再設定すればいい
- 縮小版のまま数ヶ月経ってしまっていた → 気づいた時点が再開のタイミングだと考える。空白の期間を悔やむより、今日から50%に戻すことの方に意味がある

## そのまま使えるテンプレート

```
【忙しい時期の縮小ルール】
対象の習慣:

100%(通常時):
50%(縮小版):
10〜20%(最低限):

切り替え条件(この状態になったら縮小版):

戻すタイミング(見直し予定日):
```

このテンプレートは、忙しくなる前、余裕のあるときに埋めておく。渦中で作ろうとしても、たいてい後回しになる。

## まとめ

忙しい時期や疲れている時期に習慣が途切れるのは、自然なことだ。それ自体を責める必要はない。ただ、事前に縮小版のルールを用意しておくかどうかで、その時期の過ごし方も、明けたあとの再開のしやすさも変わってくる。

次に忙しい予定が入りそうだと感じたら、その時点でこのテンプレートを一度埋めてみてほしい。
