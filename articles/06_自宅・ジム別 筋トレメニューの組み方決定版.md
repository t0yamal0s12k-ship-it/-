# 自宅・ジム別 筋トレメニューの組み方決定版

ジムに入会した日、フロアに並ぶマシンを前にして立ち尽くした。ベンチプレス、ラットプルダウン、レッグプレス……名前は何となく知っているものもあるが、今日の自分が「何を」「何回」「何セット」やればいいのかが、まったく分からない。とりあえず目についたマシンを適当に3周して、汗はかいたけれど、これで合っているのか自信がないまま帰った。[ここに体験]

自宅トレの場合はもっと自由度が高い分、逆に迷う。腕立て、スクワット、プランク……YouTubeで見た動画をつまみ食いのようにやってみるものの、「今日はこれで十分なのか」「毎日同じことをやっていいのか」がはっきりしない。

筋トレのメニューについて検索すると、「胸の日」「背中の日」といった分割の話や、種目そのものの解説は山ほど出てくる。ただ、それを自分の生活(週に何回ジムに行けるか、自宅か施設か)に当てはめて、実際に何曜日に何をやるかまで落とし込んでくれる情報は、意外と少ない。

この記事では、分割法の選び方から、週の頻度別の具体的なテンプレート、種目とセット数の当てはめ方までを、手順として書いていく。

## この記事が向いていない人

まず、すでにパーソナルトレーナーにメニューを組んでもらっている人。その場合はこの記事より、トレーナーの指示に従うほうが確実だ。

次に、器具の使い方や姿勢そのものをまだ習っていない、本当にゼロからのスタートの人。この記事は「何を・いつやるか」の組み立て方を扱うものであって、フォームの基礎を教える内容ではない。まずは施設の初回講習や、信頼できる動画・書籍で基本の動作を覚えるのが先になる。

それから、持病や怪我があり、運動そのものに医師の許可が必要な人。この記事の内容を試す前に、必ず医師に相談してほしい。

## 全体の流れを3ステップで俯瞰する

1. 自分の状況(週に何回動けるか、自宅かジムか)に合う分割法を選ぶ
2. 選んだ分割法に沿って、曜日ごとの大枠を決める
3. それぞれの日に、具体的な種目とセット数を当てはめる

分割法とは、体のどの部位を、どの日にまとめて鍛えるかという組み方のパターンのことだ。この組み方を先に決めてしまえば、毎回の「今日は何をやろう」という迷いがかなり減る。

## ステップ1:自分の状況に合う分割法を選ぶ

分割法にはいくつか種類があるが、ここでは頻度別に3パターンだけに絞って扱う。多すぎる選択肢は、かえって迷いのもとになる。

### 手順

1. 1週間のうち、トレーニングに使える日数を数える(移動時間込みで30分以上確保できる日)
2. 週2〜3日なら「全身法」、週4日なら「上半身・下半身の2分割」、週5日以上なら「部位別の3〜4分割」を候補として選ぶ
3. 選んだ分割法を、実際のカレンダーに仮で書き込んでみる(例:月・水・金など)
4. 1週間分、仮の予定として過ごしてみて、無理がないか確認する

分割法は一度決めたら固定するものではない。生活が変わればまた見直せばいい、というくらいの気持ちで選ぶほうが続けやすい。

### つまずきやすい点とその場対処

- 週に何日できるか、そもそも読めない(仕事の繁閑が激しいなど) → 少なめの日数(週2〜3日想定)で分割法を選んでおく。予定が空けば追加でやればいいだけなので、少なめに見積もるほうが挫折しにくい
- ジムと自宅、両方でやる予定がある → 曜日ごとに「ジムの日」「自宅の日」を分けて、それぞれ別のステップ2・3を作る。無理に1つのメニューに統一しなくていい

## ステップ2:曜日ごとの大枠を決める

分割法が決まったら、次は「その日は体のどこを鍛える日か」という大枠を曜日に当てはめる。

### 手順

1. 週2〜3日(全身法)の場合:トレーニングする日はすべて「全身」とする。曜日は間を1〜2日空けて配置する(例:月・木、または月・水・金)
2. 週4日(上半身・下半身の2分割)の場合:1日目「上半身」、2日目「下半身」を繰り返す(例:月=上半身、火=下半身、木=上半身、金=下半身)
3. 週5日以上(部位別3〜4分割)の場合:「胸」「背中」「脚」「肩・腕」など、部位ごとに1日を割り当てる
4. 決めた大枠を、スマホのカレンダーやメモに「◯曜日=◯◯の日」として登録する

この段階では、まだ具体的な種目は決めなくていい。「その日は体のどこを動かす日か」だけを先に固定する。

### つまずきやすい点とその場対処

- 予定が急に入って、決めた曜日にできない → その週だけ、次の空いている日にスライドさせる。無理に同じ週内に詰め込もうとせず、翌週の頭でリズムを立て直す
- 部位別に分けたはいいが、どの部位を何曜日にするか迷う → 疲労が残りやすい部位(脚など)を、翌日に予定が詰まっていない曜日に置く。それ以外は好みで決めて構わない

## ステップ3:種目とセット数を当てはめる

大枠が決まったら、それぞれの日に具体的な種目を当てはめていく。種目選びで迷い続けると初動が遅れるので、最初は「代表的な種目を1〜2個」に絞る。

### 手順

1. その日に鍛える部位について、代表的な種目を2〜3種目選ぶ(例:胸の日なら、ベンチプレスとダンベルフライなど)
2. 種目ごとに、3セット×8〜12回を基本の型として当てはめる
3. 各種目の間に、1〜2分の休憩を入れる想定で、全体の所要時間を見積もる
4. 見積もった時間が確保できる範囲に収まっているか確認し、収まらなければ種目数を減らす

最初から完璧な種目構成を目指さなくていい。数週間やってみて、時間が余れば種目を増やし、きつければ減らす、という調整で十分機能する。

### つまずきやすい点とその場対処

- 種目が多すぎて時間内に終わらない → 各部位につき種目を1つ減らす。全部を鍛えようとするより、少ない種目を確実にこなすほうが継続しやすい
- 何回・何セットが自分に合っているか分からない → 3セット×10回を基準にして、10回目がぎりぎりきつい重さを選ぶ。楽に10回できる場合は次回重さを上げる、10回に届かない場合は重さを下げる、という単純な調整でいい

## そのまま使えるテンプレート

```
【週間トレーニングメニュー】
分割法:(全身 / 上半身・下半身 / 部位別)

月曜:部位( )種目1( )種目2( )種目3( )
火曜:
水曜:
木曜:
金曜:
土曜:
日曜:

各種目共通:3セット×8〜12回、セット間1〜2分休憩
```

まずは1週間分、このテンプレートを埋めて動いてみる。埋めた内容通りにできなくても、大枠(曜日と部位)さえ守れていれば十分だと考えていい。

## まとめ

筋トレのメニュー作りで迷うのは、情報が足りないからではなく、情報が多すぎて自分の生活に当てはめる手順が抜け落ちているからのことが多い。分割法を選び、曜日に大枠を当てはめ、種目とセット数を決める。この3段階を一度作ってしまえば、次から「今日は何をやろう」と考える必要はほぼなくなる。

まずは今週の分から、仮でいいので当てはめてみてほしい。
