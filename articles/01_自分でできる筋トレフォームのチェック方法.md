# 自分でできる筋トレフォームのチェック方法

スクワットを100回やった日のことを覚えている。数字だけ見れば頑張った日のはずなのに、翌日腰が変な感じで張っていて、「あれ、フォーム間違えてたかも」と急に不安になった。[ここに体験]

ジムでバーベルを担いでいるとき、隣の人のフォームは妙にきれいに見えるのに、自分の動きはどこかぎこちない。動画を撮ってはみたものの、正直どこを見ればいいのか分からず、結局「まあ大丈夫だろう」で片付けてしまう。そんな経験がある人は、たぶん少なくない。

パーソナルトレーナーをつけていれば毎回指摘してもらえる。でも独学でやっている人、あるいはジムに月数回しか行けない人にとって、フォームの正誤判断は永遠の悩みだ。ネットで「スクワット フォーム」と調べれば一般論は出てくる。膝がつま先より前に出ないように、背中を丸めないように——そういう話は確かに正しい。でも、それを「自分の動画」にどう当てはめるかまでは、たいてい書いていない。

この記事では、その「当てはめ方」を扱う。抽象的な注意点の羅列ではなく、スマホ1台で自分のフォームを実際にチェックする手順そのものを書いていく。

## この記事が向いていない人

先に断っておきたいことがいくつかある。

まず、定期的にパーソナルトレーナーについてもらっていて、毎回フォームを見てもらえている人。この記事の内容は、あくまで「自分一人で確認する」ための代替手段なので、プロの目に勝るものではない。

次に、バーベルやダンベルの扱い方そのものがまだ分からない、器具の使い方を覚えている段階の人。フォームを気にする前に、まず基本的な動作の型を教材や動画で身につける方が先になる。

それから、明らかな痛みが出ている人。この記事はあくまで「フォームの見た目」をチェックする内容であり、痛みの原因を診断するものではない。痛みが続く場合は、遠慮なく専門家に見てもらってほしい。

## 全体の流れを3ステップで俯瞰する

やることは大きく3つに分かれる。

1. 撮影の準備をする(どこにスマホを置くか、何倍速で見返すかを決める)
2. 見るべきポイントを種目ごとに絞り込む(全部を一度に見ようとしない)
3. 実際に撮って、チェックリストと照らし合わせる

言葉にすると当たり前に思えるかもしれないが、実際にやってみると「2」で挫折する人が多い。見るべきポイントが多すぎて、結局何が正解か分からなくなるからだ。だからこの記事では、種目ごとに見る場所を絞り込んだ状態で手順化している。

## ステップ1:撮影の準備をする

### 手順

1. スマホを床から膝の高さくらいの位置に固定する(スタンドがなければ本やケースを積んで代用する)
2. 種目に応じてカメラの向きを決める。スクワットは正面と真横の2方向、デッドリフトは真横、ベンチプレスは頭の斜め上から見下ろす角度が確認しやすい
3. 画面の中に、体の動く範囲がすべて収まっているか確認してから録画を開始する
4. 普段通りのセット(重量・回数)を1セットだけ撮影する。フォームを意識しすぎて動きが変わると、意味がなくなる

ここで大事なのは「1セットだけ」という点だ。全セット撮ろうとすると見返す気力がなくなる。まず1セットで十分。

### つまずきやすい点とその場対処

- スマホが倒れて画角がずれる → 三脚がなければ、水を入れたペットボトルを重しにしてケースを挟むだけでもかなり安定する
- ジムによっては撮影が禁止・要確認の場合がある → 事前にスタッフに確認する。自宅トレなら気にしなくていい

## ステップ2:種目別に見るべき3点に絞る

すべての関節を一度に見ようとすると、必ず混乱する。種目ごとに、優先して見る場所を3つだけに絞る。

### スクワット

1. 真横の映像で、膝がつま先より大きく前に出ていないかを確認する
2. 正面の映像で、膝が内側に入り込んでいないかを確認する
3. 真横の映像で、しゃがんだときに背中が丸まりすぎていないかを確認する

### デッドリフト

1. 真横の映像で、バーが体から離れすぎていないか(スタート位置)を確認する
2. 真横の映像で、腰が反りすぎ・丸まりすぎになっていないかを確認する
3. 引き上げる瞬間に、肩がバーより前に出ていないかを確認する

### ベンチプレス

1. バーが胸のどの位置に触れているかを確認する(毎回位置がぶれていないか)
2. 肘の角度が極端に広がりすぎていないかを確認する
3. お尻がベンチから浮いていないかを確認する

### 手順(動画の見方)

1. 撮った動画を0.5倍速、可能なら0.25倍速で再生する
2. 動きの「一番深いところ」(スクワットならしゃがみ切った瞬間など)で一時停止する
3. 静止した画面で、上記3点それぞれに◯・△・×をつける
4. ×がついた項目だけを、次のステップで扱うテンプレートに書き出す

### つまずきやすい点とその場対処

- スロー再生機能がない機種を使っている → 動画アプリの再生速度変更機能(標準の写真アプリやYouTubeにアップロードする方法など)を使う。それでも難しい場合は、コマ送りで確認できるアプリを1つ入れておくと後々便利
- 「これくらいなら大丈夫」の基準が分からない → 完璧な角度を求めすぎない。前回の自分の動画と比べて、明らかに悪化しているかどうかで判断すると気が楽になる

## ステップ3:チェックリストに記録して、次回と比較する

一度チェックして終わりにしないことが、この作業を意味あるものにする分かれ目だ。

### 手順

1. 種目名・日付・使用重量をメモの一番上に書く
2. 上記の3点チェックの結果(◯△×)を記録する
3. ×がついた点について、次回意識することを1行だけ書く(欲張って複数書かない)
4. 次回撮影時に、前回のメモを先に読んでから撮る

### そのまま使えるテンプレート

```
【フォームチェック記録】
種目:
日付:
重量 × 回数:

チェック1( ):
チェック2( ):
チェック3( ):

次回意識すること(1つだけ):

気づいたこと(自由記入):
```

このテンプレートをメモアプリに保存しておいて、撮影のたびにコピーして使う。1回で完璧に直そうとせず、1つずつ直していくくらいの気持ちでいい方が、結果的に長続きする。

## つまずきやすい箇所まとめ

ここまでの中でも特につまずきやすいのは、「動画を見返す時間を作れない」という点だ。撮ったはいいが、忙しさにかまけて見ないまま放置してしまう人は多い。対処としては、撮影した直後、着替える前の数分でその場で確認してしまうのがいい。時間が経つほど見る気が失せるからだ。

もう一つは、「×が多すぎて心が折れる」パターン。フォームを一度に全部直そうとすると、逆にぎこちなくなる。1回のチェックで直す項目は1つに絞る、というルールを自分に課すくらいでちょうどいい。

## まとめ

フォームのセルフチェックは、地味で手間がかかる作業だ。それでも、撮る角度を決め、見る場所を絞り、記録を残すという型さえ作ってしまえば、毎回ゼロから悩む必要はなくなる。

トレーナーの目には及ばないかもしれないが、「自分の動きを客観的に見る習慣」自体が、長期的にはケガのリスクを減らし、伸び悩みに気づくきっかけにもなる。今日のセットから、まず1本だけ撮ってみてほしい。
