# 筋トレの停滞期(プラトー)を抜け出す具体策

トレーニング記録を見返すと、ベンチプレスの重量が「60kg×8回」のまま、もう6週間動いていない。毎回同じ重さ、同じ回数。フォームも大きく崩れているわけではない。それなのに、7回目でバーが止まる。8回目は気合いで押し切る。そんな週がずっと続いている。

この「同じ数字がずっと変わらない」状態のことを、停滞期、あるいはプラトーと呼ぶ。筋トレを続けていれば、多くの人が一度はぶつかる壁だ。ネットで検索すると「休養を取ろう」「栄養を見直そう」といった一般論は出てくるが、それだけを試しても状況が変わらないことは珍しくない。停滞期には実はいくつかの原因パターンがあって、原因によって打つべき手が違う。

この記事では、停滞期の原因をいくつかのパターンに分けたうえで、それぞれに対してどう動けばいいかを、手順として扱っていく。

## この記事が向いていない人

まず、筋トレを始めてまだ1〜2ヶ月しか経っていない人。この時期の伸び悩みは、多くの場合フォームや基礎的な負荷設定の見直しで解決することが多く、いわゆる停滞期とは性質が異なる。

次に、痛みや違和感を伴う状態で重量が上がらない人。それは停滞期ではなく、怪我や不調のサインである可能性がある。無理に重量を追わず、まず体の状態を優先してほしい。

それから、すでにトレーナーと一緒にメニューを見直している人。専門家の目で個別に調整してもらえる環境があるなら、この記事の一般的な手順より、そちらを優先したほうがいい。

## 全体の流れを3ステップで俯瞰する

1. 停滞期の原因を、いくつかのパターンに分けて特定する
2. 特定した原因に応じて、種目・重量・回数のどれかを意図的に変える
3. 変化を加えた後、一定期間様子を見てから次の判断をする

停滞期の厄介なところは、原因が1つとは限らないことだ。だからこそ、闇雲に「もっと頑張る」ではなく、原因を絞り込んでから手を打つ順番が大事になる。

## ステップ1:停滞期の原因をパターンに分けて特定する

同じ停滞期に見えても、背景にある原因は人によって違う。まずは自分がどのパターンに近いかを確認する。

### 手順

1. 直近2週間のトレーニング記録を見返し、重量だけでなく、毎回の体調・睡眠時間・食事量も一緒に書き出す
2. 「重量が変わらないだけで、体感の疲労感も変わらない」場合は、刺激そのものへの慣れ(同じ負荷の繰り返し)を疑う
3. 「重量が変わらず、体感の疲労感が以前より強い」場合は、回復不足(睡眠・栄養・休養日の不足)を疑う
4. 「重量は変わらないが、フォームが崩れがちになっている」場合は、そもそもの負荷設定(重すぎる、または補助動作が弱い)を疑う

この3パターンのうち、複数に当てはまることもある。その場合は、最も当てはまりが強いものから順に対処していく。

### つまずきやすい点とその場対処

- 記録をつけていなかったので、2週間分を振り返れない → 今日から2週間、まず記録だけをつけることを先にやる。停滞期の対処は、この記録なしにはほぼ始められない
- どのパターンにも当てはまる気がして絞れない → 一番手をつけやすいもの(例えば休養日を増やす)から試してみる。完璧に原因を特定できなくても、1つずつ試すこと自体が前進になる

## ステップ2:原因に応じて種目・重量・回数のどれかを変える

原因のパターンが見えたら、そこに対応する変化を1つだけ加える。複数同時に変えると、何が効いたのか分からなくなる。

### 手順(刺激への慣れが原因の場合)

1. メインの種目はそのままに、補助種目を1つ、これまで使っていなかったものに入れ替える
2. 同じ部位でも、可動域や角度が違う種目(例:フラットベンチからインクラインベンチへ)に変更する
3. 2〜3週間、その構成で継続し、メイン種目の重量に変化が出るか確認する

### 手順(回復不足が原因の場合)

1. 直近のトレーニング頻度を、1週間だけ意図的に1回減らす(ディロード週として扱う)
2. その週は重量も普段の6〜7割程度に落とす
3. 翌週から通常の重量に戻し、伸びが再開するか確認する

### 手順(負荷設定が原因の場合)

1. メイン種目の重量を、現在より1段階軽くする(目安として現在の90%程度)
2. 軽くした重量で、フォームを崩さず10〜12回を3セットこなせるか確認する
3. 2週間ほどかけて、少しずつ重量を戻していく

### つまずきやすい点とその場対処

- 重量を落とすことに抵抗があり、なかなか実行できない → 「後退している」のではなく「土台を作り直している」期間だと捉え直す。ディロード後に伸びが再開するケースは珍しくない
- 種目を変えたら、逆に今までできていた重量が扱えなくなった → 新しい種目は慣れるまで数回かかるのが普通のことなので、最初の1〜2回で判断せず、3週目まで様子を見る

## ステップ3:変化を加えた後、一定期間様子を見てから次を判断する

1回変化を加えただけで、翌週にすぐ結果が出るとは限らない。ここで焦って次々と手を変えると、何が効いたのかがますます分からなくなる。

### 手順

1. 変化を加えた日をメモに記録する
2. その変化を、最低でも2〜3週間は継続する
3. 2〜3週間後、記録を見返して、重量・回数・体感疲労のいずれかに変化があったか確認する
4. 変化がなければ、ステップ1に戻って別の原因パターンを疑う

停滞期を抜けるには、思っているより時間がかかることが多い。数週間単位で見る前提を持っておくと、途中で不安になりにくい。

### つまずきやすい点とその場対処

- 2〜3週間待つ間に、モチベーションが下がってしまう → 重量以外の指標(体感の軽さ、フォームの安定度など)にも目を向ける。数字が動いていなくても、質が上がっていることはよくある
- 何度か原因パターンを試しても変わらない → その場合は、食事量そのものが不足している可能性も含めて見直す。停滞期の原因が、トレーニング内容ではなく食事にあるケースも一定数ある

## そのまま使えるテンプレート

```
【停滞期チェックシート】
対象種目:
停滞している重量・回数:
直近2週間の体感疲労(強い/普通/弱い):
直近2週間の睡眠・食事の変化:

疑われる原因パターン:(慣れ / 回復不足 / 負荷設定)
今回加える変化:
開始日:
確認予定日(2〜3週間後):
```

## まとめ

停滞期は、頑張りが足りないから起きるとは限らない。むしろ、同じ刺激を繰り返しすぎていたり、回復が追いついていなかったりすることのほうが多い。原因をパターンで絞り込み、1つずつ変化を加えて、数週間単位で様子を見る。この順番を守るだけで、闇雲に追い込むより早く抜け出せることがある。
