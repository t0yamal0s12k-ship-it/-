# モチベーションが下がっても行動を止めない仕組み

雨が降っている月曜の朝、目覚ましが鳴った瞬間に「今日はいいか」という声が頭に浮かぶ。習慣を始めた最初の数週間は、やる気に満ちていたはずなのに、今はその日の天気や疲れ具合で、あっさりやらない選択をしてしまう。そして一度休むと、翌日も「昨日休んだし」という理由が積み重なっていく。

「モチベーションを上げる方法」というテーマは、探せば大量に出てくる。目標を紙に書く、ご褒美を用意する、仲間を見つける……どれも間違ってはいないのだろうけれど、こうした方法の多くは「モチベーションが高い状態を作る」ことを目指していて、そもそも「モチベーションに頼らずに行動する」という発想では書かれていないことが多い。

この記事では、モチベーションを上げる方法ではなく、モチベーションが下がっている日でも行動そのものが止まらないようにする、仕組みの作り方を扱う。

## この記事が向いていない人

まず、モチベーションの波に振り回されず、淡々と続けられている人。この記事の内容は、そういう人にとってはすでにやっていることの言語化にすぎないかもしれない。

次に、燃え尽きに近い状態で、そもそも心身の休養が必要な人。行動を止めないための工夫より、まず休むことを優先すべき状態であれば、この記事の内容は後回しにしてほしい。

それから、まだ何を習慣にしたいか決めていない人。この記事は「決めたことを、やる気に関係なく続ける」段階の話を扱っている。

## 全体の流れを3ステップで俯瞰する

1. モチベーションに頼らなくても行動できる「環境」を先に整える
2. どんなに気分が低い日でも実行できる、最低限の行動(ミニマムタスク)を決めておく
3. 感情を挟まずに行動に移すための、判断を省くルールを作る

モチベーションは天気のようなもので、コントロールしようとすること自体に無理がある。この記事が扱うのは、天気に関係なく傘を持って出かけられるようにするための、仕組みの話だ。

## ステップ1:モチベーションに頼らなくても行動できる環境を整える

やる気が高いときは、多少環境が悪くても行動できる。問題は、やる気が低い日にどれだけ余計な障害があるかだ。まず、行動を始めるまでの手間を減らす。

### 手順

1. 習慣に必要な道具(トレーニングウェア、教材、楽器など)を、使う直前の動作の近くに置く(例:翌朝使うウェアを、寝る前にリビングに出しておく)
2. 行動を始めるまでに必要な手順の数を数える(準備→移動→開始、など)
3. その手順のうち、前日までに終わらせられるものを、あらかじめやっておく
4. 「始めるまでの手間」が2手順以内になるよう調整する

やる気が低い日ほど、準備の手間が多いと「やらない理由」になりやすい。環境を先に整えておくことで、その理由自体をなくしてしまう。

### つまずきやすい点とその場対処

- 前日に準備する余裕がない日もある → 準備そのものを習慣の一部に組み込む。「準備をする」を、その日のタスクの最初の1つとしてカウントしてしまえばいい
- 環境を整えても、結局始める気になれない → その場合は、次のステップのミニマムタスクに切り替える。環境整備だけで解決しない日があるのは自然なこと

## ステップ2:気分が低い日でも実行できる最低限の行動を決めておく

「今日はやる気がない」と感じた日のために、あらかじめ「これだけはやる」という最低ラインを決めておく。

### 手順

1. 普段の行動量を基準に、その5分の1程度の量を「最低ライン」として決める(例:普段30分の練習なら6分、普段10ページの読書なら2ページ)
2. 最低ラインは、「これならどんな気分でもできる」と思えるレベルまで、必要なら何度でも下げる
3. モチベーションが低いと感じた日は、普段の量を目指すのをやめ、この最低ラインだけをやると決める
4. 最低ラインを終えた後、続けたい気持ちがあれば続けてもいいし、そこで終えてもいい

ポイントは、「今日はやる気がないから最低ラインで」と決めた時点で、それを妥協ではなく計画通りの選択として扱うことだ。

### つまずきやすい点とその場対処

- 最低ラインをやり始めたら、逆に何もしないほうが楽だった気がしてやめてしまう → 最低ラインの基準をさらに下げる。「6分」がきつければ「道具を出すだけ」でもいい。行動として何かが発生していれば、それでいい
- 最低ラインばかり続いて、量が全然増えない期間が続く → それでも構わない。ゼロの日が続くよりも、最低ラインで途切れずに続いているほうが、後から量を戻しやすい

## ステップ3:感情を挟まずに行動に移すための判断を省くルールを作る

「今日はやる気があるか、ないか」を毎回考えること自体が、行動を止める原因になっていることがある。判断そのものを省くルールを作る。

### 手順

1. 習慣を行うタイミングを、時間や場所で固定する(例:「夜9時になったら」「駅に着いたら」)
2. そのタイミングが来たら、モチベーションの有無を考える前に、ステップ1で整えた環境に体を向ける(道具を手に取る、その場所に移動する、など)
3. 体を向けた後、ステップ2の最低ラインを実行する
4. 「今日はやる気があるかどうか」を自問する場面自体を、意識的に減らしていく

考える前に体を動かす、という順番を徹底するほど、モチベーションの波に左右されにくくなる。

### つまずきやすい点とその場対処

- タイミングが来ても、つい「後でやろう」と先延ばしにしてしまう → タイミングと行動の間に何も挟まらないようにする。「後でやろう」と思う余地があるのは、間に別の選択肢(スマホを見る、休憩するなど)が挟まっているからのことが多い
- 固定したタイミングそのものが、日によって守れない → タイミングを1つに絞らず、「メインの時間」と「予備の時間」の2つを用意しておく。メインの時間を逃しても、予備の時間で最低ラインだけ実行する

## まとめ

モチベーションが下がる日は、誰にでもある。それ自体をなくそうとするより、下がった日でも行動が止まらない仕組みを先に作っておくほうが、現実的だ。環境を整え、最低ラインを決め、判断を省くタイミングを固定する。この3つがあれば、やる気に関係なく、行動だけは続けられる可能性が高くなる。

次にやる気が出ない日が来たら、この仕組みを試してみてほしい。
