# 筋トレ後のプロテイン・食事タイミングと量の決め方

ジムの先輩は「トレーニング後30分以内に飲まないと意味がない」と言う。よく見る動画では「タイミングよりも1日の総量のほうが大事」と言っている。別のサイトでは「就寝前にも飲んだほうがいい」とある。結局、今日のトレーニング後、何を、いつ、どれだけ摂ればいいのか、毎回振り出しに戻って迷う。

プロテインや食事のタイミングについての情報は、探せばいくらでも出てくる。ただ、それぞれの情報が微妙に違うことを言っていて、しかも「あなたの体重・目的の場合はこう」というところまで落とし込んでくれる情報は少ない。結果として、なんとなく毎回同じようにシェイカーを振っているだけで、それが自分にとって適量なのかどうか、確信が持てないまま続けている人は多いと思う。

この記事では、細かい理論の話よりも、「自分の体重をもとに、今日から何を、いつ、どれだけ摂ればいいか」を決めるための、実践的な手順を扱っていく。

## この記事が向いていない人

まず、持病(腎臓や肝臓に関わる疾患など)があり、たんぱく質の摂取量について医師の指導を受けている人。この記事の内容は一般的な目安であって、医療的な指導に優先するものではない。

次に、すでに管理栄養士やトレーナーから具体的な食事指導を受けている人。個別に調整された内容がある場合は、そちらを優先してほしい。

それから、極端な減量や増量など、専門的な栄養管理が必要な競技者。この記事は、日常的にトレーニングを続けている人向けの一般的な目安を扱うもので、競技レベルの調整には対応していない。

## 全体の流れを3ステップで俯瞰する

1. 自分の体重をもとに、1日に必要なたんぱく質量の目安を出す
2. 目安の量を、1日の食事とプロテインにどう配分するかを決める
3. トレーニング前後の具体的なタイミングと、外食時の代替案を用意する

理論を覚えるより先に、自分専用の数字を1つ出してしまう。数字さえ決まれば、あとはその数字に近づける作業になるので、毎回悩む必要がなくなる。

## ステップ1:自分の体重をもとに、1日の目安量を出す

### 手順

1. 自分の体重(kg)を確認する
2. その体重に1.6をかけた数字を出す(これが1日のたんぱく質摂取量の下限の目安になる)
3. 同じ体重に2.0をかけた数字も出す(これが上限の目安になる)
4. 下限と上限の間の数字を、自分の1日の目標量として仮決定する(例:体重60kgなら、96〜120gの間で、108gなど)

この数字はあくまで目安であり、体質や活動量によって前後する。「だいたいこのくらい」という基準を持つことが目的で、厳密に守ることが目的ではない。

### つまずきやすい点とその場対処

- グラム数だけ言われてもピンとこない → 鶏むね肉100gにたんぱく質約20〜25g、卵1個に約6g、プロテイン1杯に約20gが含まれる、という目安を頭に置いておく。次のステップでこの目安を使う
- 目標量が思ったより多く、達成できる気がしない → 最初から完璧な数字を目指さず、下限の数字(体重×1.6)を最初の目標にする。慣れてきたら少しずつ上限に近づければいい

## ステップ2:1日の量を、食事とプロテインに配分する

目標量が決まったら、それを「食事から摂る分」と「プロテインで補う分」に分ける。全部をプロテインで摂ろうとすると、逆に飲みすぎになりやすい。

### 手順

1. 1日の食事(3食)で、意識せずに摂れているたんぱく質量をざっくり見積もる(肉・魚・卵・大豆製品がどれくらい食卓に並ぶか思い出す)
2. 見積もった食事分を、ステップ1で出した目標量から引く
3. 残った分をプロテインで補うと決める(1杯20g換算で、1日に何杯必要か計算する)
4. 1日2杯以上になる場合は、トレーニング後と、食事だけでは足りない時間帯(朝食前後など)に分けて飲む計画にする

食事だけで足りている日は、無理にプロテインを追加しなくていい。プロテインはあくまで「足りない分の補充」という位置づけで考えると、量の判断がしやすくなる。

### つまずきやすい点とその場対処

- 食事から摂れている量を見積もるのが難しい → 最初の3日間だけ、食べたものをメモに書き出してみる。感覚がつかめたら、以降はメモをやめても大体の見積もりができるようになる
- プロテインの回数が増えすぎて負担に感じる → 1日1〜2杯を上限にして、それ以上は食事(ゆで卵、豆腐、ツナ缶など)で補う方向に切り替える

## ステップ3:トレーニング前後の具体的なタイミングと外食時の代替案

### 手順

1. トレーニング前は、開始の1〜2時間前までに、消化の負担が少ない食事(おにぎり、バナナなど)を摂る
2. トレーニング後は、可能であれば1〜2時間以内を目安にプロテインまたは食事を摂る(30分以内に必ず摂らなければ効果がなくなる、というほど厳密なものではない)
3. その日の夕食で、たんぱく質を含む主菜(肉・魚・大豆製品など)を1品以上入れることを意識する
4. 外食が続く場合は、定食屋や社食で「肉・魚のメイン+副菜」の組み合わせを選ぶ、コンビニなら「サラダチキン」「ゆで卵」「無糖ヨーグルト」を1品足す、といった代替案をあらかじめ決めておく

「◯分以内」という数字にこだわりすぎず、「その日のうちに、食事全体でどれだけ摂れたか」を見る方が、長期的には現実的だ。

### つまずきやすい点とその場対処

- トレーニング直後、食欲がなくて食べられない → 固形物が厳しい場合は、プロテインドリンクやゼリー飲料など、飲みやすい形から先に摂る。固形の食事は、少し時間を置いてからでいい
- 外食続きで、たんぱく質が偏った食事になりがち → 完璧を目指さず、「今日は難しかった日」として翌日に少し多めに摂る、というくらいの調整で十分。1食単位ではなく、数日単位で帳尻を合わせる感覚でいい

## まとめ

プロテインや食事のタイミングに関する情報が食い違って見えるのは、それぞれが少しずつ違う前提を話しているからだ。大事なのは、細かい理論を全部覚えることではなく、自分の体重に基づいた目標量を1つ持ち、それに近づけるための配分とタイミングを決めておくこと。

まずは自分の体重で、目標量の数字を1つ出すところから始めてみてほしい。
