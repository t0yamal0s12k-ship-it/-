# 耳コピ・コード採譜が上達する具体的な手順

同じ4小節を、たぶん30回は聴き直した。それでもコードが「Cなのか、Amなのか」で毎回迷う。動画サイトのコメント欄に「耳コピしてみました」という投稿を見つけて開いてみても、コードが微妙に自分の感覚と違う。どっちが正しいのか、結局分からないまま終わる。

耳コピ(音源だけを聴いて、コードや音を聴き取って楽譜やコード譜に起こす作業)をやろうとして、こういう壁にぶつかった経験がある人は多いと思う。「耳を鍛えれば聴き取れるようになる」という話はよく聞くけれど、じゃあ具体的に何をどんな順番で聴けばいいのかは、意外と教えてもらえない。

音楽理論の本を開けば、コードの構成音の説明はたくさん載っている。でも、それを実際の曲を聴きながらどう当てはめていくかという「作業手順」までカバーしている情報は少ない。

この記事では、曲を1曲丸ごと耳コピする前提で、実際にどこから手をつけて、どんな順番で聴き、どう答え合わせをしていくかを手順として書いていく。

## この記事が向いていない人

まず、コードネーム(C、Am、G7といった記号)を見てもピンとこない、コードそのものの概念にまだ慣れていない人。この記事は「コードは知っているが、耳で聴き取れない」段階の悩みを扱うので、コードの基礎を先に押さえる方が近道になる。

次に、絶対音感を身につけたい、あるいは音大受験レベルの聴音を目指している人。この記事は「趣味や弾き語りで使える耳コピ」を目的にしていて、専門的な聴音訓練とは目指すところが違う。

それから、耳コピよりも先に、楽譜を読むこと自体に苦手意識がある人。楽譜が読めないこと自体が悩みの場合は、まずそちらを別に扱う方がいい。

## 全体の流れを3ステップで俯瞰する

1. 耳コピしやすい環境とツールを整える
2. 低い音(ベース音)から先に聴き取る
3. ベース音を手がかりにコードを絞り込み、答え合わせをする

多くの人が最初からコード全体を一度に聴き取ろうとして挫折する。この記事では、あえて「低い音から」という順番にこだわって進めていく。

## ステップ1:耳コピしやすい環境とツールを整える

耳のよさの問題ではなく、環境の問題でつまずいている人は意外と多い。まずここを整える。

### 手順

1. 曲の再生速度を落とせるアプリ・サービスを1つ用意する(動画サイトの再生速度変更機能や、専用の耳コピアプリなど)
2. 曲を4〜8小節ごとに区切って、その部分だけをリピート再生できるようにする
3. コードを書き込む用のシンプルなメモ(小節を四角で区切った紙、またはメモアプリの表)を用意する
4. イヤホンかヘッドホンを使う。スピーカーよりも低音が聴き取りやすくなる

最初の曲選びも重要になる。低音がはっきり聴こえるアコースティックな曲や、楽器の少ない曲から始める方が、聴き取りの成功体験を積みやすい。

### つまずきやすい点とその場対処

- 再生速度を落とすと音程まで変わってしまうアプリを使っている → 「テンポだけを変えて音程を保つ」機能があるアプリを選び直す。多くの動画サイトや音楽再生アプリに標準搭載されている
- 曲全体を一気に聴こうとして疲れる → 4小節だけに区切ってから始める。1回のセッションで扱う範囲を小さくするほど、集中力が続く

## ステップ2:低い音(ベース音)から先に聴き取る

コード全体を一度に聴き取ろうとすると、音が重なって何がなんだか分からなくなる。先にベースの音(一番低い音)だけを追いかけると、聴き取りの手がかりが一気に増える。

### 手順

1. 対象の4小節をリピート再生しながら、ベースの音だけに意識を向けて聴く(他の楽器はいったん無視する)
2. ベースの音の高さが変わるタイミングで、鍵盤やギターで同じ高さの音を探して合わせる
3. 見つけた音の名前(ドレミ、またはCDEFGABなど)を、メモの各小節の下に書き込む
4. 1小節ごとに、ベース音が変わっているか・同じままかを確認しながら次の小節に進む

ベース音は多くの場合、そのコードの「ルート音」(コードの一番の基準になる音)と一致することが多い。ここが分かるだけで、コードの候補がかなり絞られる。

### つまずきやすい点とその場対処

- ベースの音域が低すぎて、楽器の音と合わせにくい → 1オクターブ上で仮に合わせてもいい。オクターブが違っても、音の名前(ドの仲間かレの仲間か)さえ合っていれば次のステップに進める
- どこがベースの音か分からず、メロディーと混同してしまう → 曲によってはベースが目立たない場合もある。その場合は、伴奏楽器の一番低い音を代わりに追いかける

## ステップ3:ベース音を手がかりにコードを絞り込み、答え合わせをする

ベース音が分かれば、そこから乗る和音の候補はかなり限られる。ここで初めて、コード全体の聴き取りに進む。

### 手順

1. 見つけたベース音を基準に、そのベース音をルートとするコードの候補を2〜3個書き出す(メジャー・マイナー・セブンスなど、知っている範囲でいい)
2. 候補のコードを実際に楽器で鳴らしながら、原曲と重ねて聴き比べる
3. 一番違和感が少なかった候補を、そのコマの答えとして仮決定する
4. 次の小節に進み、同じ手順を繰り返す
5. 4〜8小節終わったら、最初から通して再生し、全体の流れとして違和感がないか確認する
6. 違和感がある箇所だけ、もう一度ステップ1に戻って聴き直す

一度で完璧に当てようとしないことが大事だ。仮決定→通して聴く→修正、というサイクルを回す方が、結果的に早く正解にたどり着く。

### つまずきやすい点とその場対処

- 候補のコードがどれもしっくりこない → メジャー・マイナー以外の可能性(セブンスコードや、ルートが違う可能性)も疑ってみる。それでも分からない場合は、いったんその小節を保留にして先に進む方が全体が完成しやすい
- 自分の耳に自信が持てず、答えに確信が持てない → 完成後、コード進行をコード検索サービスや理論的な定石(よく使われる進行のパターン)と照らし合わせて確認する。100%当たらなくても、練習素材としては十分に使える

## そのまま使える耳コピ記録テンプレート

```
【耳コピ記録シート】
曲名:
対象区間(小節):

小節1:ベース音( )/コード候補( )/仮決定( )
小節2:ベース音( )/コード候補( )/仮決定( )
小節3:ベース音( )/コード候補( )/仮決定( )
小節4:ベース音( )/コード候補( )/仮決定( )

通して聴いた感想:
違和感があった箇所:
```

このシートを曲ごとにコピーして使う。1曲通してではなく、4小節単位で埋めていく方が、途中で挫折しにくい。

## まとめ

耳コピが苦手だと感じている人の多くは、実は「耳が悪い」のではなく、「聴く順番」が定まっていないだけということが多い。全部を一度に聴こうとせず、ベース音から絞り込み、仮決定して通しで確認する。この繰り返しが、結果的に一番遠回りに見えて近道になる。
