# 人からの指摘・批判を受けた時に感情的にならず受け止める具体的な手順

会議中、上司の一言で耳の奥がカーッと熱くなる。心臓がやけに速く打っているのが分かる。頭の中では「反論しなきゃ」「いや、でも」という言葉がぐるぐる回っていて、結局その場では何も言えないまま会議が終わる。家に帰ってから、ようやく言い返したかった言葉が浮かんでくる。

こういう瞬間は、仕事の場面に限らない。友人からの何気ない一言、SNSのコメント、家族からの指摘。誰かに何かを指摘されたとき、頭では「冷静に聞こう」と分かっていても、体が先に反応してしまう。そしてその反応のせいで、内容を正しく受け取れないまま終わってしまうことがある。

「指摘は成長のチャンス」「批判は気にしないほうがいい」——そういう言葉は、正直、何の役にも立たないことが多い。分かっていてもできないから困っているわけで、必要なのは心構えの話ではなく、指摘を受けたその瞬間に体と頭をどう動かすかという、具体的な手順のほうだ。

この記事では、指摘や批判を受けた瞬間から、その場でどう振る舞い、後でどう消化するかまでを、順を追って扱っていく。

## この記事が向いていない人

まず、指摘や批判を受けても、もともと動じにくいタイプの人。そういう人にとっては、この記事に書く内容はおそらく当たり前すぎて退屈だと思う。

次に、受けている指摘が明らかに理不尽な暴言や、人格そのものを否定するようなハラスメントに当たる場合。この記事は「妥当な指摘を感情的にならず受け止める」ことを扱っていて、そもそも相手の言い方や態度に問題がある場合の対処法(距離を取る、然るべき部署に相談するなど)は別の話になる。そちらは我慢するのではなく、周囲や専門の窓口に相談することを優先してほしい。

それから、慢性的に気分の落ち込みが続いていたり、日常生活に支障が出るほどつらさを感じていたりする人。この記事の内容は日々の指摘への対処法であって、専門的なケアの代わりにはならない。

## 全体の流れを3ステップで俯瞰する

1. 指摘を受けた瞬間の体の反応を、その場で鎮める初動をつくる
2. 言われた内容を「事実」と「解釈」に分けて聞き直す
3. その場で返す言葉と、後でじっくり振り返る言葉を分けて用意する

大事なのは、「感情的にならないようにしよう」と気合いで頑張ることではない。感情が動くこと自体は止められない。止められるのは、その感情のまま行動してしまうかどうかの部分だけだ。

## ステップ1:受けた瞬間の体の反応を鎮める初動をつくる

指摘を受けた瞬間、頭より先に体が反応する。ここで無理に「冷静になろう」と思っても、たいてい逆効果になる。まずは体のほうに直接働きかける。

### 手順

1. 指摘の言葉を聞いた瞬間、口を開く前に、鼻から3秒かけて息を吸う
2. そのまま4秒かけて口からゆっくり息を吐く
3. 息を吐き切ったところで、一度だけまばたきを意識的にする(視線をリセットする動作として使う)
4. その後に初めて、相手の顔を見て話し始める

この呼吸のあいだ、無言の時間が数秒できる。気まずく感じるかもしれないが、実際には数秒程度の沈黙で相手が不審に思うことはほとんどない。むしろ、間を取ってから話し始める人だと受け取られることの方が多い。

### つまずきやすい点とその場対処

- 動揺が強すぎて、呼吸どころではなくなる → その場合は、無理に何か言おうとせず「少し考えさせてください」と一言だけ返す。返答を保留にすること自体、立派な対処になる
- 呼吸をしている間、相手の言葉を聞き逃してしまいそう → 呼吸に集中するのは息を吸って吐くまでの数秒だけでいい。それ以降は普通に話を聞くことに意識を戻す

## ステップ2:言われた内容を「事実」と「解釈」に分けて聞き直す

指摘がつらく感じるのは、多くの場合、相手が言った言葉そのものよりも、自分の中でその言葉に付け加えた「解釈」のほうが大きなダメージを与えているからだ。ここを分けて聞き直すと、受け止め方が変わる。

### 手順

1. 相手が言った言葉を、できるだけそのままの表現でメモに書き出す(その場でメモできなければ、後からでもいい)
2. 書き出した言葉のうち、相手が実際に口にした部分に線を引く。これを「事実」とする
3. 「事実」以外の部分、つまり自分の頭の中で勝手に付け足した解釈(「もう見放された」「能力がないと思われた」など)を別の欄に書き出す
4. 「事実」の欄だけを見て、指摘の中身を改めて確認する

例えば「この資料、抜け漏れが多いね」という言葉自体は事実だが、それを「センスがないと思われた」と解釈するのは、自分が付け足した部分になる。この2つを分けるだけで、指摘そのものの大きさが実際よりずっと小さいことに気づくことがある。

### つまずきやすい点とその場対処

- 事実と解釈の区別が難しく、どこまでが相手の言葉か分からなくなる → 迷ったときは「相手が実際に口にした単語」だけを事実側に入れる。感情を表す言葉(冷たい、責められた、など)は基本的に解釈側になることが多い
- 書き出しても、解釈のほうが正しい気がしてしまう → その場ではどちらが正しいか判断しなくていい。ただ「分けて書く」ことだけをやる。判断は翌日以降、落ち着いてからでも遅くない

## ステップ3:その場で返す言葉と、後で振り返る言葉を分けて用意する

指摘を受けたその場で、完璧な返答をしようとする必要はない。むしろ、その場用の言葉と、後で考える用の言葉をあらかじめ分けておくと、負担がかなり減る。

### 手順

1. 指摘を受けたその場では、「ご指摘ありがとうございます、確認します」など、内容を受け取ったことだけを伝える短い一言を用意しておく
2. その場で反論したくなっても、いったんこの一言だけで区切る
3. 落ち着いたタイミング(その日の夜など)で、ステップ2で書き出したメモを見返す
4. 見返した上で、指摘に納得できる部分と、そうでない部分を分けて書き出す
5. 納得できない部分については、後日、冷静な状態で相手に確認や説明を求めるかどうかを判断する

その場で全部を解決しようとしないことが、結果的に冷静な対応につながる。その場の一言と、後からの振り返りを分けるだけで、感情的な反応をその場にとどめずに済む。

### つまずきやすい点とその場対処

- その場で何も言い返せなかったことを、後になって引きずってしまう → 「その場で反論しない」は逃げではなく、選んだ対処法だったと捉え直す。その日のうちに振り返りのメモを書くところまでやれば、対処としては完結している
- 振り返っても、まだモヤモヤが消えない → 無理に消そうとしなくていい。モヤモヤが残ったまま、次に似た場面が来たときにこの手順をもう一度使う、というくらいの気持ちで十分

## そのまま使えるテンプレート

```
【指摘を受けた時の記録シート】
日付:
場面:

相手が言った言葉(事実):

自分が付け足した解釈:

その場で返した言葉:

納得できる部分:

納得できない部分・後で確認したいこと:
```

指摘を受けた直後にこのシートを書き出す習慣をつけておくと、感情が強く出た日ほど、この作業自体が落ち着くための時間として機能する。

## まとめ

指摘や批判を受けたときに感情的になってしまうのは、性格の弱さではなく、体が先に反応する仕組みのせいであることが多い。呼吸で初動を整え、事実と解釈を分け、その場と後の対応を分ける。この3つの手順を、まずは次に指摘を受けた場面で1つだけでも試してみてほしい。
