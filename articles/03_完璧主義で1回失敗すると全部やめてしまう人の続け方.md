# 完璧主義で1回失敗すると全部やめてしまう人の続け方

「昨日サボったし、もういいか」

この一言で、それまで続けてきた習慣が丸ごと終わる。1週間続けていようが、1ヶ月続けていようが関係ない。1回途切れた瞬間に、なぜか「振り出しに戻った」ような気持ちになって、そのまま二度と再開しない。

不思議なのは、これが意志の弱い人だけに起こる現象ではないということだ。むしろ真面目で、物事をきっちりやりたいタイプの人ほどこの罠にはまりやすい。「毎日やる」と決めたのに1日抜けてしまうと、その「毎日」という記録がもう完璧ではなくなる。完璧でなくなった時点で、続ける意味を見失ってしまう——そんな感覚に心当たりがある人は、きっと少なくないはずだ。

この記事は、その「1回の失敗が全部を台無しにする」という感覚そのものにアプローチする内容だ。精神論で「気楽に考えよう」と言うのではなく、具体的にどんなルールを自分に課せば、1回のサボりが致命傷にならずに済むかを手順として書いていく。

## この記事が向いていない人

まず、そもそもまだ何も習慣化しようとしていない人。この記事は「一度始めたものが続かない」段階の悩みを扱うので、これから何を始めるか自体を考えている人には、少し先の話になる。

次に、完璧主義がまったく気にならないタイプの人。3日サボっても平然と4日目から再開できる人には、この記事の内容はおそらく不要だ。

それから、うつ状態や強い自己否定感を伴っていて、専門的なケアが必要な状態にある人。この記事はあくまで習慣づくりの工夫の話であり、メンタルヘルスの治療に代わるものではない。しんどさが強い場合は、専門家に相談することを優先してほしい。

## 全体の流れを3ステップで俯瞰する

1. 「失敗」の基準を自分の中でゆるめておく(何をもって失敗とするかを事前に決め直す)
2. サボった翌日にやることを、あらかじめ決めておく
3. 記録の付け方を「連続日数」から別の形に変える

ここで大事なのは、モチベーションを上げる話ではないということだ。モチベーションは日によって上下するもので、そこに頼ると結局同じ壁にぶつかる。この記事が扱うのは、モチベーションが下がった日でも致命傷にならないための「仕組み」の話になる。

## ステップ1:「失敗」の基準を先にゆるめておく

完璧主義の人がつまずく最大の原因は、実は「サボったこと」そのものではない。「サボった=失敗した」という自分ルールを、無意識のうちに設定していることにある。

### 手順

1. 今取り組んでいる習慣について、「これをやったら失敗」というルールを紙に書き出す(例:1日でもやらなかったら失敗、など)
2. そのルールを、意識的に「2日連続でやらなければ失敗」というルールに書き換える
3. 書き換えたルールを、目につく場所(スマホの待ち受け、手帳の最初のページなど)に置いておく

たった1日空くことは、失敗ではなく「休み」として扱う。この線引きを事前にしておくかどうかで、翌日の行動がまったく変わってくる。

### つまずきやすい点とその場対処

- 「2日連続」でもハードルが高く感じる → さらにゆるめて「3日連続」で試してみる。最初は自分が拍子抜けするくらいゆるいルールでいい。厳しさは後からいくらでも足せる
- ルールをゆるめること自体に抵抗を感じる(サボりを許すみたいで嫌だ) → これは「サボりの許可」ではなく「継続の可能性を残すための線引き」だと捉え直す。1日休んだ人と、そのまま完全にやめた人とでは、1年後の結果がまったく違う

## ステップ2:サボった翌日にやることを事前に決めておく

サボった当日の夜、あるいは翌朝は、一番判断力が落ちている瞬間だ。ここで何も決めていないと、「もういいか」という結論に流れやすい。だからこそ、この瞬間の行動は、元気なときに先回りして決めておく。

### 手順

1. 「1日サボった翌日にやる最小限の行動」を、普段の半分以下の量で決めておく(例:普段30分の筋トレなら、翌日は5分だけでもいいことにする)
2. その最小限の行動を、具体的な言葉でメモしておく(「疲れてたら5分だけでもやる」など)
3. サボった翌日、まずその最小限の行動だけをやる。それ以上やるかどうかは、やってから決める

ここでのコツは、「サボった分を取り戻そう」としないことだ。取り戻そうとすると負荷が上がり、また挫折しやすくなる。むしろ普段より軽くしてでも、途切れさせないことを優先する。

### つまずきやすい点とその場対処

- 「5分だけ」のつもりが、結局やらずに終わる → 5分すら重ければ、さらに下げて「道具を準備するだけ」「1分だけ座る」でもいい。行動自体をやめるのではなく、行動の大きさを変える
- 再開した日に、以前と同じ量をやろうとして疲れて逆効果になる → 最初の1〜2回は、意図的に「物足りないくらい」で終える。量を戻すのは、再開してから数日経ってからでいい

## ステップ3:記録の付け方を「連続日数」から変える

連続日数だけを記録していると、1日途切れた瞬間に数字がゼロに戻り、それが強い喪失感につながる。この記録方法自体を変えることで、心理的なダメージを減らせる。

### 手順

1. カレンダーやアプリで、「実施した日」に印をつける形式にする(連続日数のカウントはやめる)
2. 1ヶ月ごとに、印がついた日の合計数だけを見る(連続記録ではなく、月間の実施率を見る)
3. 途切れた翌日以降も、印を淡々とつけ続ける。過去の空白を気にしない

「何日連続か」ではなく「今月何回できたか」という見方に変えるだけで、1日のサボりが持つ心理的な重さがかなり軽くなる。

### つまずきやすい点とその場対処

- 記録アプリの多くが「連続記録」を強調する仕様になっている → 連続記録が表示されるアプリを使っている場合は、あえてその数字を見ない、もしくはシンプルなカレンダーアプリや手帳に切り替える
- 月間の実施率を見ても、低いとやはり落ち込む → 実施率よりも、「途切れた後に再開できたかどうか」に注目する。再開できた回数自体が、継続力の証拠になる

## そのまま使えるテンプレート・文例

自分ルールを書き換えるときの文例:

```
【継続ルール】
対象の習慣:
「失敗」の基準:2日連続でやらなかったら失敗とする
サボった翌日の最小行動:
再開時に唱える一言:「今日は0分から1分でも進めればOK」
```

サボった翌朝、頭の中で唱える一言も決めておくと効果的だ。例えば「昨日は休み。今日は最小行動だけやる」と、声に出さなくても心の中で繰り返すだけで、判断のブレが減る。

## まとめ

完璧主義の人が習慣を続けられないのは、意志が弱いからではなく、「失敗」の基準が厳しすぎることが多い。基準をゆるめ、サボった翌日の行動を先に決め、記録の付け方を変える。この3つは、どれも今日から始められる小さな工夫だ。

1回サボったところで、それは終わりではない。むしろ、そこからどう戻るかの練習を積み重ねることの方が、長い目で見れば意味を持つはずだ。
