# 二度寝欲求を断つ具体的な起床後5分の手順

6時30分。目覚ましが鳴る。手を伸ばして止める。そして次に気づいたら7時15分になっている——この45分がどこに消えたのか、本人にも説明できない。

こういう朝を何度繰り返しただろうか。「早起きする」と決めた前の晩の自分は、意志が固かったはずだ。なのに朝になると、その決意はどこかに消えていて、布団の重力だけが異常に強くなる。

世の中の早起き記事には「前日の夜に準備をしよう」「睡眠の質を上げよう」といった話が多い。それはそれで正しいのだけれど、多くの人が本当に困っているのは、実は「目が覚めた、その瞬間からの数分間」だ。夜の準備をどれだけ完璧にしても、当日の朝、二度寝の引力に負けてしまえば意味がない。

この記事では、その「起きてから最初の5分間」だけに焦点を絞る。夜の話はしない。朝、目が覚めた瞬間に何を、どの順番でやるかという、ごく短い時間の手順の話をする。

## この記事が向いていない人

まず、そもそも睡眠時間が慢性的に足りていない人。1日4〜5時間睡眠が続いているような状態では、どんな起床テクニックを使っても、体が休息を要求してくる。この記事より先に、睡眠時間そのものを見直す方が優先度は高い。

次に、シフト制などで起床時刻が毎日大きく変わる人。この記事の手順は「決まった時間に起きる」ことを前提にしているので、そのままでは当てはまりにくい部分がある。

それから、すでに二度寝と無縁の人。そういう人には正直、この記事に書く内容は物足りないはずだ。

## 全体の流れを3ステップで俯瞰する

1. 目覚まし音が鳴った瞬間の「最初の1動作」を固定する
2. 体を覚醒させる3つの刺激を、決まった順番で入れる
3. 二度寝したくなる瞬間の「言い訳」を先に潰しておく

ポイントは、「起きるかどうか」を毎朝考えないようにすることだ。考えている時点で、たいてい負ける。考える前に体が動く状態を作る、というのがこの記事全体の狙いになる。

## ステップ1:目覚ましが鳴った瞬間の「最初の1動作」を固定する

多くの人が失敗するのは、目覚ましを止めた後、何をするかを決めていないことだ。「止める→何もしない→また目を閉じる」という流れが、無意識にできあがってしまっている。

### 手順

1. 目覚まし(スマホ)を、手を伸ばして届かない場所に置く。ベッドから起き上がらないと止められない距離にする
2. 目覚ましを止めたら、そのまま座った姿勢を5秒キープする(横になり直さない)
3. カーテンを開ける、または部屋の照明をつける(スマホを置いた場所の近くに設置しておくと動線がつながる)

この3つを「起きてから最初にやる動作」として固定する。考える前に体が動くようになるまでは、正直かなり意識的にやる必要がある。数日で自動化されるものではない。

### つまずきやすい点とその場対処

- スマホを遠くに置くと、そもそも目覚ましの音で完全に起きられない → 音量を上げる、または振動と音の両方が鳴るタイプの目覚ましを併用する
- 座った姿勢を保てず、また横になってしまう → 座る場所を「布団の中」ではなく「布団の外(床やイスなど)」に変える。物理的に布団から出ていれば、二度寝までの距離が遠くなる

## ステップ2:体を覚醒させる3つの刺激を順番に入れる

脳がまだ「起きるか、寝るか」を天秤にかけている状態のとき、外からの刺激で天秤を起きる側に傾ける。使う刺激は、光・水・体温の3つ。

### 手順

1. カーテンを開けて(すでにステップ1でやっていれば)、光を10〜30秒ほど直接見ない程度に浴びる
2. コップ1杯の水を飲む(前の晩に枕元やすぐ手の届く場所に用意しておく)
3. 顔か手首に冷たい水を数秒当てる(洗面所が遠い場合は、濡らしたタオルを枕元に置いておいてもいい)

この3つを、この順番でやる。光→水分→体温刺激、という順にしているのは、光を浴びるのが一番手間がかからず、最初のハードルが低いからだ。いきなり冷水から始めると、そこでやる気が折れる人もいる。

### つまずきやすい点とその場対処

- 冬場、カーテンを開けてもまだ真っ暗 → タイマー付きの照明や、目覚まし内蔵のライトを使う。光が入らない時間帯は、光ではなく「音」や「動作」を先に持ってくる
- 水を用意し忘れる → 寝る前のルーティンに「コップに水を入れる」を1項目追加する。これは朝ではなく夜にやることなので、忘れないよう目覚まし本体のそばに水の入ったコップを置く場所を決めておくと定着しやすい

## ステップ3:二度寝したくなる瞬間の「言い訳」を先に潰す

ここまでやっても、数分後にまた眠気が襲ってくることがある。「あと5分だけ」という気持ちが出てくる瞬間だ。この言い訳は、事前に潰しておける。

### 手順

1. 前の晩に、起きてすぐやる「ごく小さな1つの作業」を決めておく(例:コーヒーを淹れる、決まったニュースを1本読む、など)
2. その作業に必要な道具を、寝室から出てすぐの場所に前もって用意しておく
3. ステップ2まで終えたら、考える間を与えずにその作業に取りかかる

「あと5分」という誘惑に対抗する一番効果的な方法は、意志力で我慢することではなく、次にやることを体が覚えている状態にしておくことだと感じている。意志力に頼ると、眠い朝ほど負ける確率が上がる。

### つまずきやすい点とその場対処

- 「ごく小さな作業」を決めたのに、当日忘れてしまう → 前夜、道具を目に入る場所(玄関、洗面所の鏡など)に置いておく。視界に入れば思い出す
- 作業自体が面倒に感じて結局やらない → 作業のハードルをさらに下げる。「コーヒーを淹れる」が重ければ「水を飲みながら1分だけ座る」でもいい。ハードルの高さは、その日の眠さによって毎回変わっていい

## そのまま使える朝5分の手順表

```
【起床後5分ルーティン】
0:00 目覚まし停止(座った姿勢をキープ)
0:05 カーテン・照明で光を入れる
0:20 水を1杯飲む
0:40 顔か手首に冷水を当てる
1:00 前夜に決めた小さな作業に取りかかる
```

この時間配分は目安であって、厳密に守る必要はない。順番と「何をやるか」が決まっていることの方が、時間の正確さよりずっと重要だ。

## まとめ

二度寝を防ぐ方法として世の中に出回っている情報の多くは、「夜の過ごし方」に偏っている。もちろんそれも大事だが、実際に多くの人がつまずいているのは、目が覚めた直後の数分間だ。

考える前に体が動く状態を作ること、言い訳が浮かぶ前に次の行動を用意しておくこと。この2つを、まずは1週間だけ試してみてほしい。毎朝完璧にできなくても、それはそれで構わない。
